Formulaire d'inscription en PHP

Un mini-projet web simple en PHP qui permet :
- de valider un formulaire côté serveur,
- d'insérer des utilisateurs dans une base de données MySQL,
- et d'afficher la liste des clients enregistrés.

## ✨ Fonctionnalités

- Validation côté serveur (nom, email, mot de passe, âge)
- Vérification d’unicité de l’email
- Connexion à MySQL avec `mysqli`
- Affichage des erreurs utilisateur
- Interface responsive simple en HTML/CSS
- Liste dynamique des clients
